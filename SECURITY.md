# Security

While the open source code we share through this repository is not considered critical infrastructure, security remains a major consideration in all our software development practices.

## Reporting Security Concerns

If you discover a security vulnerability or have security concerns regarding any of our repositories, please report it to us by emailing our security team at:

githubsecurity[at]banenor[dot]no

Please include detailed information about the potential vulnerability to help us address it promptly. We appreciate your efforts in responsibly disclosing your findings and will work diligently to address any valid concerns.
